# A4 照片排版工具 V3

在原 V2 的基础上加上&#x4E86;**「导出的 PDF 可以再导入回来继续编辑」**、  
**「排版可选 1×1 / 2×2 / 3×3 …（默认 3×3）」**，并顺手修掉了几个会影响出片质量的毛病。

## 新功能：PDF 可以再编辑

### 怎么用

1. 排好版，点「导出PDF」。
2. 想继续改的时候，把那个 **PDF 直接拖到左侧列表**（或点「导入 PDF」）。
3. 程序会把它恢复成可编辑的照片列表，接着调整顺序、旋转、增删，再导出即可。

### 原理

导出时除了页面本身，还会在 PDF 里写一个独立的对象（`/Type /A4PLState`），  
里面用 zlib 压缩存了一份 JSON：

```json
{"app": "A4PhotoLayout", "v": 3, "grid": [3, 3],
 "margin_mm": 10.0, "padding_mm": 1.5, "dpi": 300,
 "images": [{"p": "C:/照片/IMG_0001.jpg", "r": 90}, ...]}
```

它不被任何页面引用，Acrobat、浏览器、打印机都会直接忽略它；本工具则能把它读回来，  
所以**顺序、旋转、排版参数都能还原，照片仍然是原始文件**（不是从 PDF 里抠出来的  
低质量副本，也不会有二次压缩损失）。

### 导入的几种情况

| 情况                                     | 结果                              |
| -------------------------------------- | ------------------------------- |
| PDF 里有编辑信息、原图都还在                       | 完全无损恢复（列表、顺序、旋转、排版都一致）          |
| 有编辑信息，但某些原图被移动/删除了                     | 缺的那几张从 PDF 页面对应的格子里抠出来顶上，其余仍用原图 |
| **不是本程序导出的 PDF**（扫描件、水印相机照片表、截图/报表导出…） | 先把页面自己合成出来，再按你选的四种方式之一拆成照片（见下）  |

导入前会先弹一个确认窗口，告诉你这个 PDF 有几页、有没有编辑信息、第一页有几张位图，  
并让你选导入方式、行列数，以及「追加到当前列表」还是「替换当前列表」。

### 不是本程序导出的 PDF：四种导入方式

程序会先按页面内容流里的 `cm`／`Do` 摆放关系，把页面上的位图**自己合成成一张整页图**  
（相当于"扫描"这一页，只需要 Pillow，不需要任何 PDF 渲染库），然后按你选的方式拆：

| 方式                | 说明                                                | 适合                  |
| ----------------- | ------------------------------------------------- | ------------------- |
| **按空白间隔自动拆分**（默认） | 先找整行空白把页面分成若干横带，再在每条横带里找整列空白，切成一张张照片；按从上到下、从左到右排序 | 水印相机照片表、多张照片拼一页、扫描件 |
| 每页作为一张整页图片        | 整页一张图（按页面真实分辨率合成，最高 600 DPI）                      | 想保留原始版面、或后面再手工裁     |
| 按网格等分拆分           | 你自己填「几行 × 几列」，按等分格子拆                              | 照片是紧挨着、中间没有白边的情况    |
| 把每页里的每一张位图分别导入    | 页面里嵌了几张位图就导入几张（不去重、不合成）                           | 照片被切成好几条存进 PDF 的情况  |

实测（一个真实的水印相机影像 PDF，横版 A4，一页里 20 张位图条）：

- 按空白间隔自动拆分 → **4 张完整的照片，2835×2126 像素**（等于原始分辨率，蓝底水印信息完整）
- 每页一张整页图片 → 1 张 7016×4961（600 DPI 的整页）
- 按 2×2 网格拆分 → 4 张 2839×2131
- 每张位图分别导入 → 20 张长条（即 PDF 内部的真实存储方式）

合成结果与独立渲染器（PyMuPDF）渲染同一页做对比，平均色差 1.75，版面、缩放、翻转方向都一致。

### 兼容性

- 读 PDF 的部分是自己写的，支持传统 xref 表、xref 流、对象流，以及  
  Flate / DCT / JPX / CCITT / LZW / ASCIIHex / ASCII85 / RunLength 等过滤器，  
  并带解析失败时的暴力扫描兜底。用 90 个真实 PDF（Acrobat 自带的模板、报告、  
  色卡等）测过，全部能正常解析或给出明确提示。
- 加密/受保护的 PDF 会明确提示「无法读取」，不会静默失败。
- 只渲染位图：纯文字/矢量页面（Word 转出来的那种）没有可提取的照片，  
  程序会提示"没有位图"，这是符合预期的（照片排版工具不需要文字渲染）。
- 如果 PDF 被其他软件「优化」过而导致编辑信息丢失，仍可按上面几种方式导入，  
  只是照片会变成 PDF 里的图像，不再是原始文件。

## 排版可选（默认 3×3）

第二行工具栏右边有「排版」下拉框，可选：

```
1 × 1    2 × 2    2 × 3    3 × 2    3 × 3（默认）    3 × 4    4 × 3    4 × 4
```

切换后立即生效：右侧预览按新排版重画，状态栏会显示「排版已切换为 2 × 2：每页 4 张，共 3 页」。

- **导出/打印**都按当前排版走；
- 导出的 PDF 里会**记录排版参数**，以后把这个 PDF 拖回来，排版会自动跟着恢复  
  （例如你用 2×2 导出的，重新导入后仍是 2×2，并会提示"已按 PDF 里的编辑信息切换到排版 2×2"）；
- 导入对话框里「按网格等分拆分」的行列数默认就是当前排版（你用 2×2，它就默认 2×2）。

典型用法：把 4 张照片排成 2×2 时，选 2×2 → 4 张正好一页，照片比 3×3 大很多。

## V3 相对 V2 的修正

1. **竖拍手机照片不再被拉伸**——V2 记录宽高时没算 EXIF 方向，渲染时又转正了图片，  
   两者不一致；现在统一按「转正之后」的尺寸记录。
2. **打印不再变形**——V2 用纸张物理尺寸硬铺满，非 A4 纸张会拉伸；现在按可打印区域  
   等比缩放并居中。
3. **打印分辨率不再跟随「导出质量」**——V2 选 2400 DPI 再打印会把内存打爆；  
   现在打印固定按打印机分辨率渲染，并限制在 300 DPI（见下）。
4. **打印画法更兼容**——改用「内存 DC + StretchBlt」，Microsoft Print to PDF  
   这类虚拟打印机也能正常出图（用旧画法画完 EndPage 会失败）。
5. **导出改成逐页流式写入**——一次只在内存里放一页，页数多也不会吃满内存。
6. **PDF 内 JPEG 质量可调**（85/90/95）——V2 用的是 Pillow 默认值 75，照片偏软。
7. **DPI 选项收敛为 150/300/450/600**，2400 这种没有实际意义又容易崩的值去掉了。
8. 打印用的 GDI 常量自己定义（`win32print` 并不导出 `PHYSICALWIDTH` 等常量，  
   V2 的打印代码每次都会静默走进异常分支）。
9. 列表显示序号、状态栏显示图片完整路径；加了快捷键；退出时自动清理临时文件。

## 打印说明

- 点「打印」后先选打印机（不使用 `win32ui.CreatePrintDialog`，避免在部分  
  pywin32 环境里弹不出来）。
- 内容会等比缩放并居中放进打印机的可打印区域，A4 版面打到 Letter 等纸张上也不会变形。
- 渲染固定在 **300 DPI**：实测 Microsoft Print to PDF 这类驱动对单页位图有大小限制  
  （300 DPI 正常，400/600 DPI 会 `EndPage` 失败），而照片打印 300 DPI 已经足够，  
  打印机会自己按真实分辨率放大。
- 选择 **Microsoft Print to PDF / XPS** 这类「文件打印机」时，它们要求先指定输出  
  文件，程序会弹一个保存对话框让你选保存位置（普通打印机不会弹）。
- 选择 **Adobe PDF** 打印机时，Adobe 会自己弹出它的「正在创建 Adobe PDF」流程和  
  保存位置对话框，按它的提示操作即可；如果弹出的窗口提示「拒绝访问」，说明 Adobe  
  的助手进程没有权限写你选的目录，换一个目录（例如桌面或文档）再试。

## 常见问题

**导入 PDF 说「没有位图」？**  
说明这个 PDF 是纯文字/矢量页面（比如 Word 转出来的），里面没有可提取的位图。  
本工具是照片排版工具，只处理位图页面。

**从 PDF 抠出来的照片质量如何？**  
等于导出时的画质（导出 DPI 与 JPEG 质量决定）。想要更好的效果，就别删原图——  
原图在的时候导入用的永远是原图。

**临时文件在哪？**  
导入时从 PDF 抠出来的图片放在 `%TEMP%\A4PhotoLayout_import_<进程号>\`，  
程序关闭时会自动删除。

**拖放没反应？**  
装 `tkinterdnd2`：`py -3 -m pip install tkinterdnd2`。
