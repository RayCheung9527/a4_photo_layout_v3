一个 Windows 下的 A4 照片排版小工具：把一批照片按网格排到 A4 页面上，导出为 PDF 或直接打印。
**导出的 PDF 可以再拖回来继续编辑**（保留原图路径、顺序、旋转、排版），
也能导入别的软件生成的图片型 PDF（扫描件、水印相机照片表等）并拆回成照片。

单文件、自包含：PDF 读写引擎直接内置，不需要装任何第三方 PDF 库。

## 功能一览

1. 添加图片（可多选），支持 JPG / JPEG / PNG / BMP / GIF / TIFF / WEBP
2. 从 Windows 资源管理器**拖入**单张 / 多张图片
3. 拖入**文件夹**，递归扫描其中的图片与 PDF
4. 自动跳过重复图片（按绝对路径归一化去重）
5. 左侧列表与右侧预览联动
6. **长按右侧图片约 0.3 秒后拖动**，调整图片顺序
7. 顺时针 / 逆时针 90° 旋转
8. 导出 A4 PDF（逐页流式写入，内存占用恒定）
9. **导出的 PDF 可以直接再导入，继续编辑**（顺序 / 旋转 / 排版都能还原）
10. Windows 打印（稳定的“选择打印机”窗口 + 正确的纸张比例 + 等比缩放居中）
11. **排版可选**：1×1 / 2×2 / 2×3 / 3×2 / **3×3（默认）** / 3×4 / 4×3 / 4×4
12. 导入第三方图片型 PDF，并支持四种拆分方式（见下）

## 运行环境

| 依赖 | 是否必需 | 用途 |
| --- | --- | --- |
| Python 3.8+ | ✅ 必需 | — |
| Pillow | ✅ 必需 | 图片读写、缩放、旋转、EXIF 方向修正 |
| tkinterdnd2 | ⭕ 可选 | 从资源管理器拖拽文件进来 |
| pywin32 | ⭕ 可选 | Windows 打印 |
| numpy | ⭕ 可选 | 读取被压缩过的 PDF 图像时快很多（纯加速） |
